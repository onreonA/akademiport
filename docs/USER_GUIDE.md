## Admin Dashboard

### Overview

As an **Admin**, you have full access to manage the entire platform, including programs, companies, users, and project templates.

### Key Features

#### 1. Program Management

**Creating a Program:**

1. Go to **Dashboard** > **Programs**
2. Click **"New Program"**
3. Fill in program details:
   - Program name
   - Description
   - Start and end dates
   - Program manager (consultant)
   - Capacity
4. Click **"Create Program"**

**Managing Programs:**

- View all programs in a grid or list
- Edit program details
- Assign companies to programs
- Track program progress
- Archive completed programs

#### 2. Company Management

**Adding a Company:**

1. Go to **Dashboard** > **Companies**
2. Click **"New Company"**
3. Enter company information:
   - Company name
   - Contact person
   - Email and phone
   - Address
4. Assign to a program (optional)
5. Click **"Create Company"**

**Managing Companies:**

- View all companies
- Edit company details
- Assign users to companies
- Track company progress
- View company projects

#### 3. User Management

**Creating Users:**

1. Go to **Dashboard** > **Users**
2. Click **"New User"**
3. Select user role:
   - **Admin:** Full system access
   - **Consultant:** Manage programs and projects
   - **Company:** Access assigned projects
4. Fill in user details
5. Click **"Create User"**

**Managing Users:**

- View all users by role
- Edit user information
- Assign roles and permissions
- Deactivate users
- Reset passwords

#### 4. Project Templates

**Creating Templates:**

1. Go to **Dashboard** > **Project Templates**
2. Click **"New Template"**
3. Enter template details:
   - Template name
   - Description
   - Priority level
4. Add sub-projects:
   - Sub-project name
   - Description
   - Order
5. Add tasks to each sub-project:
   - Task title
   - Description
   - Priority
6. Click **"Create Template"**

**Using Templates:**

- Templates are reusable project structures
- Consultants can create projects from templates
- Templates can be edited and versioned

## Consultant Dashboard

### Overview

As a **Consultant**, you manage programs, companies, and projects. You create projects, assign tasks, and review completed work.

### Key Features

#### 1. Program Overview

**Viewing Programs:**

1. Go to **Consultant Dashboard**
2. View assigned programs
3. See program statistics:
   - Total companies
   - Active projects
   - Completion rate

**Managing Program Companies:**

1. Click on a program
2. View enrolled companies
3. See company progress
4. Access company projects

#### 2. Project Management

**Creating Projects:**

1. Go to **Projects** > **New Project**
2. Choose:
   - **From Template:** Select a template and customize
   - **From Scratch:** Create custom project
3. Fill in project details:
   - Project name
   - Description
   - Company assignment
   - Start and end dates
   - Priority
4. Click **"Create Project"**

**Managing Projects:**

- View all projects (by company, status, priority)
- Edit project details
- Track project progress (auto-calculated)
- Add/edit sub-projects
- Monitor task completion

#### 3. Sub-Project Management

**Creating Sub-Projects:**

1. Open a project
2. Go to **Sub-Projects** tab
3. Click **"New Sub-Project"**
4. Enter:
   - Sub-project name
   - Description
   - Status
5. Click **"Create Sub-Project"**

**Managing Sub-Projects:**

- Reorder sub-projects (drag & drop)
- Edit sub-project details
- Track sub-project progress
- Add tasks to sub-projects

#### 4. Task Management

**Creating Tasks:**

1. Open a sub-project
2. Click **"New Task"**
3. Fill in task details:
   - Task title
   - Description
   - Assigned user (company user)
   - Priority
   - Due date
4. Click **"Create Task"**

**Managing Tasks:**

- View all tasks (by status, assignee, due date)
- Edit task details
- Reassign tasks
- Change priority and due dates
- Add comments and questions

#### 5. Task Review & Approval

**Reviewing Tasks:**

1. Go to **Tasks** > **Review**
2. View tasks marked as complete by company users
3. Click on a task to review:
   - Read task description
   - Review comments
   - Check completion quality

**Approving/Rejecting Tasks:**

- **Approve:** Click **"Approve"** to mark task as done
- **Reject:** Click **"Reject"** and provide feedback
- Rejected tasks return to company user for revision

## Company Dashboard

### Overview

As a **Company User**, you view assigned projects, complete tasks, and communicate with consultants.

### Key Features

#### 1. Dashboard Overview

**What You See:**

- Assigned projects
- Pending tasks
- Completed tasks
- Recent activity

**Quick Actions:**

- View project details
- Complete tasks
- Add comments

#### 2. Project View

**Viewing Projects:**

1. Go to **Company Dashboard**
2. See all assigned projects
3. Click on a project to view details:
   - Project description
   - Timeline
   - Progress
   - Sub-projects
   - Tasks

**Project Progress:**

- Overall project completion percentage
- Sub-project breakdown
- Task status overview

#### 3. Task Completion

**Completing Tasks:**

1. Go to **Tasks** or open a project
2. Click on a task
3. Read task description and requirements
4. Click **"Mark as Complete"**
5. Add completion notes (optional)
6. Click **"Submit"**

**Task Status:**

- **Todo:** Not started
- **In Progress:** Currently working on
- **Review:** Submitted for consultant review
- **Done:** Approved by consultant
- **Rejected:** Needs revision

#### 4. Communication

**Adding Comments:**

1. Open a task
2. Scroll to **Comments** section
3. Type your comment or question
4. Click **"Add Comment"**

**Asking Questions:**

- Mark comment as a question
- Consultant will be notified
- Receive responses in the same thread

## FAQs

### General

**Q: How do I reset my password?**
A: Click "Forgot Password" on the login page and follow the instructions sent to your email.

**Q: Can I change my email address?**
A: Yes, go to Profile > Settings and update your email. You'll need to verify the new email.

**Q: How do I report a bug?**
A: Contact support at support@akademiport.com or use the feedback form in the app.

### For Consultants

**Q: Can I create custom project templates?**
A: Only admins can create templates. Contact your admin to request a new template.

**Q: How is project progress calculated?**
A: Progress is automatically calculated based on completed tasks vs. total tasks.

**Q: Can I assign multiple users to a task?**
A: Currently, tasks can only be assigned to one user at a time.

**Q: What happens when I reject a task?**
A: The task returns to "In Progress" status and the company user is notified to revise.

### For Company Users

**Q: Can I see other companies' projects?**
A: No, you can only see projects assigned to your company.

**Q: What if I can't complete a task by the due date?**
A: Contact your consultant via task comments to request an extension.

**Q: Can I reopen a completed task?**
A: No, only consultants can reopen or reassign completed tasks.

**Q: How do I know if my task was approved?**
A: You'll receive a notification and the task status will change to "Done".

### For Admins

**Q: Can I bulk import users?**
A: This feature is coming soon. Currently, users must be added individually.

**Q: How do I archive old programs?**
A: Edit the program and change its status to "Completed" or "Archived".

**Q: Can I export data?**
A: Yes, use the export feature on list pages to download CSV or Excel files.

## Tips & Best Practices

### For Consultants

1. **Create Clear Task Descriptions:** Be specific about requirements and expectations
2. **Set Realistic Due Dates:** Consider company workload and complexity
3. **Provide Timely Feedback:** Review and respond to completed tasks quickly
4. **Use Templates:** Save time by using project templates for similar projects
5. **Communicate Regularly:** Use comments to stay in touch with company users

### For Company Users

1. **Read Task Descriptions Carefully:** Understand requirements before starting
2. **Ask Questions Early:** Don't wait until the deadline to ask for clarification
3. **Update Task Status:** Keep consultants informed of your progress
4. **Meet Deadlines:** Plan your work to complete tasks on time
5. **Provide Context:** When marking tasks complete, add notes about your work

### For Admins

1. **Maintain Clean Data:** Regularly review and update user and company information
2. **Monitor System Usage:** Track active users and identify issues early
3. **Create Useful Templates:** Design templates that reflect common project structures
4. **Train Users:** Ensure all users understand how to use the platform
5. **Backup Data:** Regularly export important data for backup purposes
